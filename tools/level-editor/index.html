Level editor

Paints the ASCII grid and the entity list the game loads, and writes the exact LevelDef literal the level files are authored as. Paste one in and hit Load; the box updates as you paint. Round-tripping every shipped level through this format is covered by tests/level-source.test.ts, so what you copy out is what the game reads in.

Left click paints the selected tile or drops the selected entity. Right click erases: back to empty for tiles, and removes whatever entity is under the cursor. The grid validates on every change — a ragged row or a buried Snapper says so below rather than three screens later.
